エーワン（A-one）のA4ラベルシートへの印刷に対応することを目指した、無料・オープンソースのラベル＆カード作成ツールです。
「ラベル屋さんクラウド」が2026年12月2日19:00で終了することに伴い、代替手段の一つとして開発しています。

ブラウザだけで動きます。サーバーにデータを送りません。`index.html` をブラウザで開くだけで使えます。

## 主な機能

- 用紙プリセット15種（品番付き）: 12面 宛名標準 86.4×42.3mm（31504/72212等）、10面 86.4×50.8mm、8面、18面、21面、24面（2種）、27面、44面、65面、名刺10面 91×55mm、1面・2面・4面ほか。寸法はエーワン公式仕様と日本郵便の対応ラベル一覧で確認した実寸です
- 品番・品名・一片サイズでの用紙検索、自由設定（列・段・ラベル寸法・余白・間隔をmmで入力）
- 編集モード: 全面同じ内容／面ごとに編集／CSV差し込み（1行=1ラベル、`{列名}` テンプレート、複数ページ対応）
- オブジェクト: 通常文字（縦書き・文字間隔・フチ・影・3D）、円周文字、日付文字、図形（四角・丸・三角・五角形・六角形・星・矢印・直線・曲線）、画像、QRコード、バーコード（JAN13=チェックディジット計算つき／Code39／Code128／ISBN）、表、連番（開始番号・増分・ゼロ埋め桁数・前後文字）、カレンダー
- 編集操作: 元に戻す／やり直す、ズーム、オブジェクトリスト（重ね順・ロック・複製・削除）、位置・サイズ・角度の数値入力、整列、面コピー／クリア、印刷開始位置の指定
- 自作テンプレート6種（宛名／差出人／名刺／表示・値札／住所+QR／連番資産管理）
- 保存: ブラウザ内保存（名前付き＋自動保存）とJSON書き出し／読み込み
- 印刷: A4実寸PDF（210×297mm）。日本語は300dpi描画で埋め込むため文字化けしません。テスト印刷モード（枠線・寸法入り）、0.1mm単位の位置補正つき。印刷時は「倍率100%／実際のサイズ、用紙に合わせるオフ、A4」で印刷してください
- デザイン面のPNG／JPG書き出し

## ラベル屋さんのファイル（.aly）について

ラベル屋さんの保存形式 `.aly`（差し込み時は `.alym`）は仕様が公式に公開されていない専用形式のため、本ツールで元のレイアウトを完全再現することは保証できません（詳しくは [docs/ALY.md](docs/ALY.md)）。
本ツールには実験的な取り込み機能があり、ZIPとして開ける場合は中身のXMLを解析して、座標を持つ文字を配置し直すことを試みます。実物の `.aly` サンプルを提供いただけると、取り込み精度を上げられます。Issueでご相談ください。

なお「ラベル屋さんクラウド」に保存したファイルは、2026年12月2日19:00の終了後は使えなくなります。一括ダウンロード機能はないため、終了前にファイルを1つずつ開いて手元のパソコンへ保存し直してください。

## 使い方

1. `index.html` をブラウザで開く（または GitHub Pages 等の静的ホスティングに置く）
2. 用紙プリセットを品番で選ぶ
3. テンプレートを選ぶか、白紙からデザインする
4. テスト印刷で位置を確認してから本番PDFを印刷する

サンプルの差し込みデータは [examples/address.csv](examples/address.csv) です。
