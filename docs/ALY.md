# .aly ファイルについて（調査メモ）

## 確認できたこと

- ラベル屋さん10の保存形式は `.aly`、差し込み用は `.alym`、旧版（ソフト9）は `.lcx`（エーワン公式サポート・公式マニュアルで確認）
- PDF形式で書き出したファイルはラベル屋さんでも編集できないと公式マニュアルに明記されている。保管は `.aly` で行うのが公式の案内
- `.aly` の内部仕様は公式には公開されていない
- 独立系のWindowsアプリ「ALYラベル一括編集」（Microsoft Store）が `.aly` の読み込み・編集・PDF出力に対応しており、第三者による解析自体は可能な形式である

## 本ツールの取り込み（実験的）

1. ファイルがZIP形式であれば展開し、中のXMLをDOM解析する
2. 座標・サイズ・文字サイズらしき属性を持つ要素のテキストを、位置つきテキストとして再配置を試みる
3. ZIPでない場合は、Shift_JIS／UTF-8／UTF-16を判定して可読文字列を抽出し、候補一覧から選んで流し込めるようにする
4. 取り込み結果レポート（何件拾えたか、何が再現できなかったか）を表示する

## 開発方針（法的な線引き）

- 本ツールの取り込みは、利用者自身が作成し、利用者自身のパソコンに保存している `.aly` ファイルを、利用者のブラウザ内でのみ読み取る方式に限定します
- 公式ソフトウェア自体の逆コンパイル・逆アセンブル等のコード解析は行いません。解析対象は利用者のデータファイルだけです
- 暗号化等の技術的な保護がかかっているデータを回避して読むことはしません。開ける範囲だけを読みます
- 公式ソフトウェアから抽出したコード・定数・素材を本リポジトリに含めることはしません
- なお、ラベル屋さんの利用許諾規約にはリバースエンジニアリング禁止条項があるため、データファイル形式の解析が同条項にどう関係するかは解釈の余地が残ります。権利者から申入れがあった場合は、当該機能を速やかに無効化できる体制にします

## 限界

- 実物の `.aly` サンプルファイルが無い状態では、完全再現の検証はできない
- 図形・画像・バーコード等のオブジェクトや、書式の細部は再現できない場合がある
- サンプルを提供いただければ、実際の内部構造に合わせてパーサを改良できる
